# Original rendered sample records

These small records correspond to the complete local MP4 generated and validated during implementation. See [verification](../../docs/VERIFICATION.md) for measured results and the successful GitHub workflow links. The video is available as a three-day Actions artifact and in the task workspace; large binary videos are intentionally excluded from Git.

The sample uses evergreen fallback, so these files contain no third-party discovery signals or credentials. The independent speech check is an implementation-time verification aid, not a dependency required by the daily pipeline. Its SHA-256 identifies the local sample; each GitHub run produces a separately validated waveform.
